# FinReason-Agent: 面试现场 5 分钟屏幕共享演示剧本 (5-Minute Live Demo Script)

> **适用场景**：技术二面、主管面或现场展示环节中，面试官提出：“能屏幕共享带我们看一下系统运行效果吗？”  
> **核心心理锚点**：展现**工业级完成度**、**零幻觉底层逻辑**与**科学严谨的评测方法论**，而不是念幻灯片。

## ⏱️ 00:00 ~ 01:00：开门见山，直击行业核心痛点 (Problem Framing)

**【操作】**：
- 屏幕共享打开浏览器：`http://localhost:8501`（系统可视化工作台界面）；
- 鼠标停留在首页大标题 **“FinReason-Agent 金融刑侦级自主审计与确定性推理 Agent 系统”**。

**【解说词】**：
> “各位老师好！传统大语言模型在金融和财报审计领域落地时，有三大不可逾越的致命痛点：
> 1. 第一是**算术幻觉**：大模型本质是概率语言模型，无法在参数中准确心算复杂的跨表浮点数；
> 2. 第二是**长文档失真**：几百页财报中的断表、跨页表格与深层附注极易在提取时错位；
> 3. 第三是**成本高昂**：不管简单问题还是复杂排查，盲目单次调用大模型导致成本失控。
> 
> 为此，我独立设计并研发了这套 **FinReason-Agent**。它的核心理念是：**零算术幻觉（Code-as-Action）、语法受限认知三阶分流、以及法庭级闭环证据链**。下面我用 3 分钟向大家演示系统的核心推演全流程。”

> - **亮点 2：确定性沙箱执行层 (Zero Hallucination)**

**【操作】**：

- 页面呈现出 100 案卷通关大屏看板与混淆矩阵（TP: 50, TN: 50, FP: 0, FN: 0）。

**【解说词】**：
> “做 AI Agent 最怕的是在几个 Case 上自嗨。为了检验系统的真实泛化能力，我构建了**第四代双轨评测体系 (Dual-Track Evals)**：
> - 考卷库包含了真实 A 股/港股历史上的 **100 家上市公司**（50 起暴雷造假案 + 50 起白马健康案）；
> - 我们采用双轨制考核：
>   - **轨 1 代码直判**：只有计算值与官方真相的误差 $\le 0.1\%$，且舞弊定性完全吻合才算及格；
>   - **轨 2 双盲位置翻转去偏 (Swap Bias Test)**：将正反方案位置互换对称评测，消除大模型固有的位置偏见。
> - 在本套金标准下，系统达到了 **100.0% 的分类准确率，0 误报、0 漏报**，整个 100 题全量压测在 16 秒内全部跑通。”

## 💡 应对面试官突击提问的黄金句式 (Cheat Sheet)

- **问：这个系统如果换成海外财报（美股 10-K），能不能跑？**  
  *答：“完全可以。我们的底层科目映射层抽象为了标准的 Slug 语义命名空间（如 `monetary_funds`, `interest_bearing_debt`），只要对美股 GAAP 科目做一层词典映射，沙箱验算和 MCTS 推演逻辑是 100% 通用的。”*
- **问：MCTS 模拟次数设为多少？会不会很慢？**  
  *答：“在默认配置下，我们设定 `max_simulations=15`，深度为 3。由于模拟阶段的核心打分是由本地 DuckDB 内存沙箱毫秒级完成的，单案推演总耗时仅在 0.3~0.8 秒之间，完全满足准实时风控要求。”*
- **问：整个系统是你一个人完成的吗？花了多长时间？**  
  *答：“是的，从底层数据对齐、Code-as-Action 沙箱、MCTS 状态机引擎、双轨评测框架，到前端 Streamlit、FastAPI 和 Docker 容器化，全链路均由我独立架构并经过严格的单元测试与重构完成。”*
